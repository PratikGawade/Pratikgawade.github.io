Software developer, mountain seeker, art enthusiast, forever curious.

For 4+ years I've been the person building the things that keep our products humming: containerised microservices on Kubernetes, CI/CD pipelines in TeamCity, Vue + .NET Core dashboards for teams like CX Brand Tracker and Virgin Voyages, and the Prometheus / Grafana / ELK plumbing that keeps everything honest. What I've been up to. 🧭

From data pipelines to production microservices — a quick career timeline.

Jan 2021 — Present

💼 Software Developer · Nepa India Production Pvt. Ltd.

Four flagship projects across microservices, analytics tooling, admin dashboards and survey platforms.

Sampler

  • Containerised the Sampler microservices with Docker and deployed to Kubernetes clusters — optimised resource use and achieved 99.9% uptime.
  • Developed and maintained automated CI/CD pipelines in TeamCity using Shell scripts and Kotlin, cutting deployment times by 95% and improving release frequency.
  • Stood up comprehensive monitoring and logging with Prometheus, Grafana, and the ELK stack, cutting issue detection & resolution time by 50%.
  • Used Terraform to provision and manage cloud infrastructure, giving 100% consistency and repeatability across environments.
  • Partnered with Dev, QA and Ops to streamline workflow, reducing deployment cycle times by 30%.

Campaign Benchmark

  • Built an in-app Analysis module in ASP.NET Core (.NET 8) that replaced a legacy VBA/Excel tool — users configure filter runs, upload FiltersParams JSON to GCS, and trigger the Pub/Sub → Cloud Function → Dataflow pipeline end-to-end, eliminating a manual two-tool workflow.
  • Containerised with a multi-stage Docker build and deployed to a production GKE cluster behind an Nginx Ingress with Let's Encrypt TLS and an OIDC auth sidecar, enforcing Auth0 role-based access at both proxy and app layers.
  • Wired up Google Cloud Build CI/CD to build, push to Artifact Registry, and roll out to Kubernetes on every merge — release turnaround down to a single push.
  • Integrated GCP Workload Identity, Secret Manager, and the External Secrets Operator so no credentials live in the cluster or repo; the SQL Server connection string is sourced at runtime from Secret Manager.
  • Shipped Dataflow job-status polling with a background sweep, in-app result CSV downloads, and a pre-submit Summary modal with per-campaign breakdown — power users monitor and retrieve results without leaving the app.

Dashboards Admin — CX Brand Tracker

  • Built and maintained an intuitive admin UI in Vue.js + .NET Core Web API, replacing a manual JSON-editing process and improving operational efficiency by 90%.
  • Set up automated build & deploy pipelines in TeamCity on GCP — efficient, scalable delivery.
  • Automated JSON uploads to Google Cloud Storage, speeding up data availability by 95%.
  • Containerised the app with Docker on Kubernetes (99.9% uptime) and wired Slack APIs + TeamCity for custom build / deploy notifications.

Virgin Voyages Admin Panel

  • Built a survey & market-research platform on Vue.js, .NET Core MVC, Kafka, Docker, Kubernetes and Postgres.
  • Shipped flexible survey question types (multi-select, single-select, description-based) and integrated market research terms with a survey-health tracking system.
  • Used Kafka to notify users when surveys went live — improved engagement and response rates.
  • Built a dashboard tracking respondents and valid / invalid surveys with full analytics for decision-making.
