Here is a list of commonly used Docker commands and what each one does.

## Docker

- **`docker run`** — creates and runs a new container from a specified image.

  ```bash
  docker run hello-world
  ```

- **`docker build`** — builds a new Docker image from a `Dockerfile`. A `Dockerfile` is a text file that contains the instructions for building a Docker image.

- **`docker ps`** — lists all the running containers on your system. By default it only shows active containers; add the `-a` flag to include stopped ones.

- **`docker stop`** — stops a running container. Specify the container ID or name as an argument.

- **`docker rm`** — removes a stopped container from your system. Specify the container ID or name as an argument.

- **`docker images`** — lists all Docker images currently stored on your system.

- **`docker pull`** — downloads an image from a registry such as Docker Hub.

- **`docker push`** — uploads an image to a registry such as Docker Hub.

- **`docker network`** — manages Docker networks, which allow containers to communicate with each other.

- **`docker exec`** — executes a command inside a running container. Specify the container ID or name as well as the command to run.

- **`docker logs`** — displays the logs generated by a running container.

- **`docker inspect`** — displays detailed information about a container or image.

- **`docker commit`** — creates a new image from a running container.

- **`docker tag`** — tags a Docker image with a specific name and version.

- **`docker volume`** — manages Docker volumes, used to store persistent data generated by containers.

- **`docker system`** — provides information about the Docker system (disk space used by images/containers, etc).

## Docker Compose

Commonly used Docker Compose commands:

- **`docker-compose`** — manages multi-container Docker applications using a YAML file.
- **`docker-compose up`** — starts all services defined in a `docker-compose.yml` file.
- **`docker-compose down`** — stops and removes all containers created by `docker-compose up`, along with any networks and volumes.
- **`docker-compose build`** — builds the images defined in a `docker-compose.yml` file.
- **`docker-compose stop`** — stops all containers created by `docker-compose up`, but does not remove them.
- **`docker-compose start`** — starts all containers created by `docker-compose up`, only if they were previously stopped.
- **`docker-compose restart`** — restarts all containers created by `docker-compose up`.
- **`docker-compose ps`** — lists all containers created by `docker-compose up`, along with their status.
- **`docker-compose logs`** — displays the logs of all containers created by `docker-compose up`.
- **`docker-compose exec`** — executes a command inside a container created by `docker-compose up`.
- **`docker-compose config`** — validates and displays the configuration of a `docker-compose.yml` file.
- **`docker-compose images`** — lists all images used by the services defined in a `docker-compose.yml` file.
- **`docker-compose rm`** — removes all containers created by `docker-compose up`.
- **`docker-compose pull`** — pulls the latest versions of the images used by the services.
- **`docker-compose push`** — pushes the images used by the services to a registry.
